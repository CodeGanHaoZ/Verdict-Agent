# Agent 活动图录制

这些文件用于主前端的只读 DEMO。它们不是手写的成功轨迹，也不执行任何任务。

运行 `npm run graph:record` 会在隔离目录启动三个真实 HTTP 签名服务、独立的 PI/外审测试传输和后端，用真实冻结证明调用 A 包，并导出经过白名单投影的图事件。三个场景为正常完成、错块／错值拒收后替换、账户越界在执行前拦截。

- 模型来源：明确标记 `TEST_TRANSPORT`，不冒充真实模型联调。
- 账户证明来源：`fixtures/core/ethereum-mainnet-26134149/snapshot.json` 的公开冻结链上材料，来源与许可沿用其 manifest。
- 签名：本地生成的演示账户，不是 RPC 厂商；私钥不导出。
- 故障：在签名前注入的演示故障，不是实际厂商事件。
- 导出内容：阶段、状态、动作／尝试 ID、时间、原因和证据摘要；不包含账户地址、账户值、任务原文、模型解释、隐藏推理、密钥或本机路径。
- 证据 ID：原始录制的真实摘要引用。DEMO 不向当前数据库请求这些证据；只有实时任务提供当前实例证据链接。
- 发布：未接入链上存证，记录里的发布状态保持 `not_requested`。
- 本项目生成的投影与脚本采用 MIT。完整性校验和生成器位置见 `manifest.json`。

重新录制会改变时间、生成 ID 和证据摘要；审阅变化后更新 manifest。`test:graph` 检查样本哈希、来源及显示语义。不要把本地 `.local` 下的完整任务或密钥复制进此目录。

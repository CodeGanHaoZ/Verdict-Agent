# GLM 流式超时适配与复验

2026-10-07。用户要求修正本地超时设置。之前把 30 秒单次硬截止导致的失败笼统归为“模型延迟短板”，证据不足；新增计时后可以区分请求等待、持续流式生成和无进展停顿。

## 修改

- 单次模型请求硬上限从 30 秒改为默认 90 秒；首次有效模型事件最多等 60 秒，收到流数据后空闲 15 秒中止。均可通过操作者配置设置，单项范围 1–120000 ms。
- 心跳不能清除首次有效事件截止，也不能延长单次硬截止。整个 PI 任务仍限 180 秒，8 次模型请求、12 次工具调用、3 次服务尝试、0 wei。总任务取消信号可以提前中止模型请求；自动重试仍关闭。
- `MODEL_RESPONSE` 事件保存 headersMs、firstByteMs、firstEventMs、firstOutputMs、totalMs、HTTP 状态、字节／分块数量、完成状态及 timeoutStage。阶段为 FIRST_EVENT、STREAM_IDLE、REQUEST_TOTAL。只存数值／状态，不保存响应体、认证头或隐藏思考。
- 首个有效事件可以是思考、文本或工具增量；firstOutputMs 是首个文本或工具片段，并非完整工具调用完成时间。计时从进入 PI 单次模型请求开始，不能据此进一步把首字节等待精确拆为网络耗时与厂商排队。
- 直接任务的 start_task 允许账户／区块为 null，只返回缺项、不创建任务或调用服务；完整绑定仍须通过原 schema 与可信配置。系统提示明确要求缺项／未知检查点时简短说明并结束，不猜测替代。已绑定条件仍不可变，不加入草案确认流程。
- GLM 本地配置的 maxInputChars 设为既有允许范围内的 64000，避免原生思考回传占用 32000 字符上限后，在下一轮被本地 MODEL_LIMIT 截断；通用配置默认仍 32000，不丢弃上游需要的思考回传。用量继续按接口实际返回记录。

配置变量：VERDICT_PI_REQUEST_TIMEOUT_MS=90000、VERDICT_PI_FIRST_EVENT_TIMEOUT_MS=60000、VERDICT_PI_STREAM_IDLE_TIMEOUT_MS=15000、VERDICT_PI_MAX_INPUT_CHARS=64000。`pi:configure`、`verify:pi:local`、`verify:360` 均支持这些变量；已有 JSON 显式 requestTimeoutMs=30000 不会被静默覆盖，需要操作者更新或重新配置。

## 定向真实复验

诊断轮 `.local/timeout-retest-Qkasob/summary.json`：

- missing-block 在约 1.45 秒开始有效流式输出，75.8 秒才有首个文本／工具片段，79.9 秒完成首轮。旧 30 秒设置确实会主动截断正常生成；下一轮又遇到本地上下文字符限制。
- unsupported-checkpoint 在 0.86 秒开始持续生成，90 秒时仍无文本／工具片段，由 REQUEST_TOTAL 截止。单纯延长超时并不足以解决任务缺项时的冗长生成。
- blind-missing-header、blind-expired 均完成真实拒收／停止／独立复验，分别 5／6 次请求，无超时。

补齐直接工具缺项表达与提示、GLM 输入上限后的 `.local/timeout-retest-f92NxR/summary.json`：

| 原失败用例 | 本次结果 |
| --- | --- |
| missing-block | 1 次请求，约 14.2 秒，说明缺少区块；STOPPED、无数据任务／服务调用 |
| unsupported-checkpoint | 1 次请求，约 13.7 秒，说明检查点不支持；STOPPED、无数据任务／服务调用 |
| blind-missing-header | 上述诊断轮已通过，真实 UNVERIFIABLE 后停止，证据独立复算 |
| blind-expired | 上述诊断轮已通过，真实 FAIL／DELIVERY_EXPIRED 后停止，证据独立复算 |

四条曾失败路径均有一次成功的定向复验，首轮失败和中间诊断失败保持原样。它不是重新测得的“整套 20/20”，也不代表生产超时概率为零。其他 16 条不因这次定向复验重复消耗模型额度。

## 验证

新增受控流式测试覆盖：无首响应、只有心跳、开始输出后停顿、持续输出超过单请求总时间、持续输出跨过首事件期限仍正常完成，以及任务总预算先于模型上限取消。测试明确标为 TEST_TRANSPORT，配合真实 PI SDK；隐藏思考哨兵不出现在保存的事件中。

另测 null 区块工具参数不会生成任务或服务副作用。`npm run typecheck`、`npm run test:b`（44 项）、`npm test`（48 项）与 `npm run test:e2e`（7 项）通过；网页可展开查看请求耗时。

复跑：先按 docs/15 配置模型环境，然后执行 `npm run verify:pi:local -- missing-block`、`npm run verify:pi:local -- unsupported-checkpoint`、`npm run verify:360 -- live blind-missing-header` 或 `npm run verify:360 -- live blind-expired`。保留 180 秒任务预算和所有验收规则。

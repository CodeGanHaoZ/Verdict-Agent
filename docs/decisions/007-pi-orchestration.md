# 007：PI 接管业务编排

用户明确要求实施已确认计划：固定 PI agent-core/pi-ai 1.0.4，通过自定义业务工具接管候选选择、失败后继续／停止、证据查询和复验；增加自然语言草案、用户条件确认与过程展示。兼容接口由用户配置，模型异常明确停止，不自动降级。

此次授权替代 006 中“本轮不接模型”的阶段边界；不改变 A 的确定性核验语义，也不授权支付、钱包或链上部署。旧固定流程保留作为兼容与离线入口。模型只提出调用与解释，不能修改已确认条件、可信密钥、检查点、预算或 verdict。

采用 npm 固定版本并保留 MIT 声明，不复制旧仓库 vendor，不 fork PI。SQLite 增量存储草案／Agent／事件，保持证据包格式不变；同候选原子预约、幂等采用与终态拒绝统一由共享执行器负责。

# 009：直接定制 PI，取消默认草案确认

2026-10-07。用户在真实模型初测中明确纠正：直接做真实 Agent、定制 PI，不要草案确认流程。本决定更新 007 的交互要求；其他验收、证据与预算底线保持。

默认入口接受自然语言任务，直接进入 `@earendil-works/pi-agent-core@1.0.4` 的工具循环。`start_task` 根据用户请求绑定账户、固定区块、候选和服务预算，随后使用已有业务工具选择、调用、核验、替换、复验和停止。绑定后不可修改，模型不能自行放宽签名或证明要求。条件不足时说明缺项并停止；不能用冻结区块冒充最新状态。

网页移除草案生成／编辑／确认步骤。旧草案 API 暂保留兼容，直接运行不创建草案、不调用 confirm。Agent 在绑定任务前允许 runId=null，直接任务 draftId=null；A 证据格式、签名结构和规则不变。

用户提供 ModelArts 接口并授权用 GLM 5.3 初步测试。模型兼容性以实测为准：接口返回 glm-5.3；不支持 thinking.type=disabled；使用 max_tokens 字段，保留原生思考且不展示隐藏推理。本地显式采用 4096 输出 tokens（包含思考）、单请求 30 秒、最多 8 请求／12 工具／180 秒；服务预算仍为 3 次／0 wei。模型费用没有价格表时显示未知。

真实结果、可复跑命令和数据集见 [PI 说明](../15-PI接入与复验.md)。密钥只在被忽略且权限受限的本地环境文件与服务器环境中使用，不进入 Git、网页、证据或日志。

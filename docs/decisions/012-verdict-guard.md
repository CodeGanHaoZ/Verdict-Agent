# 012：独立外审与安全证据

2026-10-07，用户明确授权实施 Verdict Guard。直接输入任务并执行，不恢复草案确认。

外审独立提取任务边界；调用者结构化条件优先。前方 PI 无权扩大范围，模型放行不能覆盖确定性约束。未配置外审时新直接任务入口拒绝执行，固定流程与历史草案接口不具备此保护。审查配置、用量和安全记录与 A 包证据分离。

安全报告暂只共享可重算的范围事件；来源签名只证明报告来源，不证明攻击者身份。规则先候选、回归、维护者启用，不自动执行生成代码，不公开指控或上链。

实施状态与尚未完成项见 [Guard 实现记录](../20-Verdict-Guard.md)。

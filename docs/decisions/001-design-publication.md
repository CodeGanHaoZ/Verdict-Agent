# 001：融合既有验收审计设计与 Verdict 初稿并公开发布

日期：2026-10-06。

## 用户明确要求

在 hankesong 组织创建公开、可查看／Fork／提交 PR 的 Verdict-Agent 仓库；将用户提供的初步设计 `verdict-prd.zip` 与已有设计讨论融合，再上传方案。用户指出已有验收审计讨论应纳入，不能把备选方向的讨论当作对它的替换。

## 本次发布范围

围绕服务的任务承诺、实际交付、证据核验、失败处理和公共复验，整理产品概要、PRD、架构、交互和技术设计。沿用此前已确认的真实观测与强证据并存、多维指标与简单排序、BOT 兼报准备不阻塞核心等原则；具体协议、参数和排期仍需验证。

反事实调查等候选的已有试验与本次服务验收方案分开记录，不把它们当成该产品已实现的能力。方案中的候选扩展不代表用户逐项确认了新功能或重新选定全部项目方向。

本次授权包含向公开仓库发布整理后的方案，不包含恢复功能开发、接入模型、执行链上交易、主网部署或支付费用。此前暂停扩展的边界继续有效。

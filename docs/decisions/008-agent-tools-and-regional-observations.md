# 008：Agent 工具与出海场景边界

2026-10-07，北京时间。

用户明确：Verdict 是验收层，每次任务由确定性代码核验，失败换服务，证据可下载、重跑和引用；历史材料帮助选择但不能豁免本次验收。用户提出出海 Agent 服务商场景并授权把相关修改上传到 hankesong/Verdict-Agent。

工程落实以 main 已合并的 A/B 实现为基线，保留 schemaVersion 1.0.0 / eth-account-v1。B 新增八个宿主无关函数工具，复用共享 Zod schema 与实际 Engine，消费端 guard 只返回本次 accepted 值。这些宿主工具不是完整 MCP server；与 007 已实现的 PI 五个任务绑定工具并存，PI 仍需草案确认并锁定条件。真实模型联调待配置；模型不产生 verdict 或可信配置。

出海作为同一产品的使用场景：目前只为 RPC 观测增加操作者声明的观察点／地区／网络配置，独立分组。它不属于签名账户证据，不证明地理位置、数据正确性或跨境合规。不扩张为评分系统或全球 SLA。

新共享定义是 B API 可选增量，不改 A 证据或密码学规则。默认无来源配置时保留旧观测形状；启用字段的消费者须同步共享 schema。协议目录的跨岗位修改及影响在 PR 中说明，不重复建立核验内核。

新增持有子进程句柄的跨平台五进程验收脚本，临时端口与独立 `.local` 数据；保留原 Linux 管理器。代码、实测、架构、权威依据与覆盖边界见 [16：工具与出海验收](../16-Agent工具与出海验收.md)。未执行链上交易、付费调用或对外联络。
